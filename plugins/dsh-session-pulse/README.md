# dsh-session-pulse (会话状态面板)

九模式会话的作战状态面板——三件套全部直读宿主运行时（todos 投影 / 子代理目录 / 会话 chat 快照），不新建存储。

- 状态 chip（会话头部右上角）：任务进度 = 模型任务清单（todos 投影）实时汇总 `done/total` + 进度条，全部完成转绿「任务 N/N」；子代理 chip 显示 `子代理 N · K 运行中`，点击展开右侧「子智能体目录」抽屉。
- 子智能体目录（右侧抽屉）：按「正在运行 · N / 已结束 · M」分组，无运行时空态文案「没有正在运行的子智能体」；条目带状态（运行中/已完成/已结束）与形态（单次/可持续）；点击名称即进入该子代理会话查看运行内容（宿主目录寻址 openSubagent，失败回退 open）。抽屉打开期间订阅宿主目录实时成员更新。
- 提示词栏（对话页左侧居中）：会话内全部用户输入按序成列（单行省略胶囊）；悬停预览全文前 400 字（含时间与「定位」按钮）；点击定位到消息流对应位置（`data-chat-anchor-key` 锚点平滑滚动 + 高亮闪烁；不在已加载区间时提示先向上滚动加载）。仅对话标签页可见（切到图谱等标签自动隐藏）。
- 作用域：九模式会话（列表源 agentPreset 判定；宿主重启后退化时经 `/dsh-session-pulse/session.mode` 问服务端真相——agents 注册表 → composedPreset，同源信任栅栏）。

纯逻辑在 `lib/pulse.js`（进度/分组/提示词提取/模式门控，`client.js` 内为镜像实现）；服务端唯一端点 `session.mode`。测试：`node test/run.mjs`
