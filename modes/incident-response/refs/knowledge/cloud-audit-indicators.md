# 云审计日志失陷指标判读清单

> 云上应急审计线的深度手册：控制面审计日志里的"该问问为什么"信号。
> 六厂商日志源：AWS CloudTrail、阿里云 ActionTrail、腾讯云 CloudAudit、华为云 CTS、
> Azure Activity Log、GCP Cloud Audit Logs。AWS 侧 API 名写实名；其余厂商操作名以各自
> 审计产品为准（判读用关键词已给），**不要照本清单虚构具体 API 名进报告**。

## 五类指标

### ① 凭据类（谁在用什么身份）

| 指标 | 判读 | 备注 |
|---|---|---|
| 异地/多地域跳变 | 同一 AK 短窗内出现在非常用地域（对照历史基线） | 最常见的泄露首发信号 |
| 新建子账号与密钥 | CreateAccessKey/CreateUser（AWS 实名；他厂商检索"创建访问密钥/子用户"） | 结合创建者身份与时间窗——夜间/服务账号创建即高危 |
| STS 角色链异常 | AssumeRole 链路跳到非常用角色/跨账号 | 画调用链（谁→ AssumeRole → 谁） |
| 根账号使用 | root 直接调 API 或登录 | 应当几乎为零事件，出现即查 |
| 登录异常 | 控制台登录的 MFA 缺失/异地/IP 信誉差 | 各厂商登录日志单独看 |

### ② 提权类（权限怎么变大的）

- 策略绑定与变更：AttachUserPolicy/AttachRolePolicy/PutRolePolicy（AWS 实名；他厂商
  检索"授权/绑定策略/权限变更"）——尤其是 `AdministratorPolicy`/全权限类绑定；
- 组成员变更、信任策略修改（跨账号信任=后门常驻位）。

### ③ 外带类（数据怎么出去的）

| 指标 | 判读 |
|---|---|
| 快照共享/导出 | ModifySnapshotAttribute 增加外部 account 共享、跨区复制新建（检索"快照·共享/导出"）——**确定性外带通道** |
| 存储桶策略改公开 | PutBucketPolicy/SetBucketAcl 类（检索"桶策略/ACL·public"）；配合对象列举与下载量 |
| 跨区复制新建 | 复制到非常用区域 |
| KMS 解密异常 | Decrypt 调用峰值、对非常规 key 的解密、新 key 的创建后即解密 |
| 大流量出网 | 网络流日志与 CDN/中转出流量对照（辅助，非审计日志本体） |

### ④ 持久化类（怎么留下来的）

- 新建后门凭据（访问密钥不删）；
- 函数计算新触发器/新函数部署（检索"函数·创建/触发器"）；
- 镜像仓库写权限利用（镜像篡改面）；
- IAM 后门：新角色信任策略指向外部账号。

### ⑤ 踪迹清理类（本身即高危信号）

- 审计日志停止/删除：StopLogging/DeleteTrail（AWS 实名；他厂商检索"审计·停止/删除/
  跟踪"）；
- 日志投递目标变更（改向攻击者可控桶）；
- 日志保留期缩短、特定时间窗记录缺失（完整性校验：各厂商日志校验/摘要功能）。

## 判读纪律

1. **先建基线再判异常**：取失陷窗口前后各 N 天的调用画像（常用地域/常用身份/常规 API
   频度），异常=对基线的偏离，不是对绝对值的判断；
2. 每条指标进 attack-timeline 须带：时间/调用者身份（AK 指纹·用户）/源 IP/请求参数
   摘要/日志原文引用——与其他线同证据标准；
3. **凭据类与提权类是定性主证据**，外带类是影响面证据，清理类是攻击者熟练度与时间窗
   佐证；
4. 与 cloud-security 分工：本清单只做判读与定性；需要重放验证某条路径是否可行时，按
   生态流转交 cloud-security（只读优先）。

## 工作负载侧补充（与主机侧衔接）

- 实例元数据利用：IMDS 访问痕迹（169.254.169.254 出现在应用日志/流量侧）、临时凭据
  被用于控制面调用的身份回溯（审计日志里的实例角色身份异常调用）；
- 容器：K8s audit log 的 exec/secret 读取、已退出容器通过节点容器日志与镜像层追溯；
- 快照保全=云侧 I1 等价物（磁盘卷快照先做，再动任何东西）。
