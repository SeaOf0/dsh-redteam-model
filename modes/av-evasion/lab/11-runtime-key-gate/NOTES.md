# 11 运行时密钥门禁 · 技术↔检测侧配对表

原理篇：`../../refs/techniques/runtime-key-gate.md`（门禁位置/输入源谱系/失败语义/组合链/变体谱系）。

## 演示内容

| 步骤 | 命令 | 预期 |
|---|---|---|
| 构建 | `cc gate.c -o gate` | 纯 C 零依赖 |
| 密钥错误 | `./gate` / `./gate wrong` / `RUN_KEY=x ./gate` | **静默退出（exit 0，无任何输出）** |
| 密钥正确 | `RUN_KEY=demo-key-2026 ./gate`（或 `./gate demo-key-2026`） | 打印解密后的演示配置 |
| 失败路径系统调用观察 | `strace -f ./gate wrong 2>&1 \| grep -cE "socket\|connect\|openat.*key"` | 0——判定纯内存（可与任何正常样本对照） |

## 技术↔检测侧配对

| 技术侧设计 | 检测侧对策（实验时逐条自验） |
|---|---|
| 门禁先于配置解密（密钥错→配置从未进内存） | 失败样本内存转储无配置字符串——取证侧必须转旁证（流量/父子关系/启动环境） |
| 输入源三选（argv/env/内嵌自检）零系统调用 | argv/env 受控枚举重放（模糊空间探测）；qemu/unicorn 指令级跟到门禁分支 patch 跳转后重放 |
| 静默 exit 0 干净退场 | **"过干净"= IOC**：零外联零落盘零报错的疑似样本应深挖而非放行；同族交叉验证排除空壳误判 |
| 与反沙箱（时钟对表）串联成前置链 | 真实时钟沙箱过第一道门；第二道门只能靠密钥探测/patch |

## 变体实验（扩展方向）

- 失败语义变体：延时后退出 / 错误密钥下走 decoy 无害行为（消耗分析时间）；
- 位置变体：门禁后移到首次任务下发前；多门禁串联（不同模块各自校验）；
- 输入源变体：argv[0] 伪装名校验、多因子（参数+环境变量同时匹配）、内嵌主机绑定自检。

## 边界如实登记

- 对指令级动态分析+patch 无免疫力（纯内存分支）——价值在抬高**自动化分析**成本，不防人工逆向；
- 本演示为原理教学（解密产物为占位演示串），不构成可部署载荷；检测侧对策须在判定环境实测后方入镜像表。
