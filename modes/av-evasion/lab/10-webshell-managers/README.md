# 通用连接器生态魔改免杀（四工具 + 客户端侧）

| 工具 | 协议面 | 默认特征（被打点处） | 魔改主面 |
|---|---|---|---|
| 菜刀 | 明文 urlencoded | 全签名（基线/对照组） | —（历史位） |
| 蚁剑 | 编码器层（可插拔） | 默认编码器特征串 | 自定义编码器（成本最低） |
| 冰蝎 | AES 对称加密+密钥协商 | 静态密钥可推/默认 Header | 密钥派生+协商+结构变形 |
| 哥斯拉 | AES/XOR 加密器+Cookie 通行证 | Header 弱特征/马结构/客户端指纹 | 马重构+JAR 重打包+协议自定 |
| 客户端侧 | — | JAR/配置落地特征 | 去特征重打包/mini-client 复刻/内存加载 |

- 共同检测残留面：**密钥可得即可解密**（应急取证工具对魔改版仍有效——密钥来自客户端
  配置或内存 dump）；HTTP 行为异常模型不受加密影响；马侧静态族指纹需与流量侧分别对抗。
- 决策：新任务首选「自研马+mini-client」（零工具指纹）；存量生态继续用时走魔改四路。
